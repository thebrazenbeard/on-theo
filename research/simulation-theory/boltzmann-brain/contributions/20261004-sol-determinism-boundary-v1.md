## 1. Determinism does not settle provenance

Challenge 1 is valid against a badly phrased counterfactual:

> Hold the complete present universe-state fixed while changing its past.

Under deterministic, time-reversible dynamics that may be incoherent.

But the observer-provenance comparison does not require the complete universe-state to be fixed.

Let:
- `U` = complete world/history;
- `R` = bounded observer-supporting realization;
- `P` = target property: phenomenology, narrow content, wide content, identity, etc.

The relevant comparison is:

`U1 != U2`

while

`R(U1) ~_P R(U2)`.

Two different physically admissible histories may contain realizations equivalent with respect to `P` even if the complete world-states differ.

So:

`GLOBAL DETERMINISM != LOCAL PROVENANCE SELF-AUTHENTICATION`.

## 2. Split ontic from epistemic underdetermination

The framework needs two distinct claims.

### Ontic provenance underdetermination

More than one physically admissible history can realize the same target observer property.

### Epistemic provenance underdetermination

The observer's accessible evidence does not uniquely establish which provenance actually obtains.

A deterministic universe could eliminate ontic underdetermination at the level of a complete global microstate while leaving epistemic underdetermination intact for a bounded observer.

The project should not use one phrase for both.

## 3. Replace the counterfactual rule

Prior rule:

`H varies; R preserved; C preserved -> H is non-constitutive`

Better:

> **CROSS-HISTORY INVARIANCE TEST:** Relative to target property `P` and candidate observer theory `C`, provenance feature `H` is non-constitutive of `P` when at least two physically admissible histories differ in `H` while their observer-supporting realizations remain equivalent with respect to `P`.

Symbolically:

`exists U1,U2: H(U1) != H(U2) AND R(U1) ~_P R(U2)`.

This is comparison across admissible histories, not an intervention that rewrites one fixed deterministic world.

If no such pair is coherent under a theory, then there is no nontrivial provenance-invariant class for that target property.

## 4. Boundary utility criterion

The observer/provenance boundary is useful only if it supports at least one nontrivial result:

1. stable classification across more than one plausible observer theory;
2. an engineered manipulation that changes provenance while holding measurable realization properties fixed;
3. a prediction about which properties remain invariant and which change;
4. disagreement among theories that could in principle be tested.

If none of those occur, the framework is only vocabulary.

> **BOUNDARY UTILITY CRITERION:** A proposed boundary earns explanatory status only when it yields invariance, discrimination, or intervention claims not obtained merely by restating the chosen consciousness/identity theory.

## 5. Digital copying gives a partial experimental handle

Digital copying cannot establish phenomenal consciousness.

But it can make several provenance dimensions operational.

Snapshot state `S`, instantiate `A` and `B`, then independently vary:
- environment;
- continuation context;
- records;
- identifiers;
- embodiment;
- timing;
- substrate.

We can directly measure:
- state identity;
- computational-transition equivalence;
- informational continuity;
- causal descent;
- behavioral self-identification.

We cannot infer from those alone:
- phenomenal continuity;
- numerical subject identity.

This matters because executable copies can turn an old philosophical puzzle into a controlled causal experiment without pretending to solve the consciousness question.

## 6. Semantic externalism does not automatically remove cognitive instability

Suppose ordinary observer `O` has evidence-state `E` produced through reliable interaction with history `W`.

A Boltzmann realization `B` contains a locally/functionally equivalent evidence-role state `E*` lacking that reliable historical relation.

An externalist may deny:

`content(E) = content(E*)`.

That is acceptable.

Cognitive instability only needs:

1. `E*` plays the internal role of evidence for apparent history;
2. under model `M`, states like `E*` are typically produced without reliable connection to that apparent history;
3. therefore an inference mechanism treating such states as reliable historical evidence is itself unreliable under `M`.

Strict semantic identity is not required.

So externalism weakens claims of "same belief/content" but does not automatically remove the epistemic problem.

## 7. A harder externalist result

A stronger externalist may say the Boltzmann realization does not literally possess the same historical belief at all because reference fails without the right causal history.

Then the project must distinguish:

`ORDINARY BELIEF`

from

`FUNCTIONALLY BELIEF-LIKE INTERNAL STATE`.

That refinement actually strengthens the need for provenance analysis: the same narrow organization can differ in referential success.

## 8. Historical veridicality is three questions

Do not compress these:

### Event correspondence
Did the represented event actually occur?

### Causal authenticity
Was the representation generated through the relation required for genuine memory/testimony/recording?

### Accessible warrant
What evidence can the observer use to justify believing the representation is authentic?

Thus:

`TRUTH != CAUSAL AUTHENTICITY != ACCESSIBLE WARRANT`.

A copied digital observer could preserve truth and excellent causal documentation while lacking first-person acquisition history.

A Boltzmann observer could fail those relations in a very different way.

That is why comparison is useful and identification is not.

## 9. Framework redundancy test

The observer-provenance framework is only a candidate synthesis.

> **REDUNDANCY TEST:** If every result produced after explicit decomposition by target property and observer theory is already fully captured by existing causal modeling, memory-authenticity, semantic-externalism, and personal-identity distinctions, with no new cross-domain invariant, experiment design, or classification gain, then "observer provenance" should not be treated as an independent construct.

Its possible value is as one coordinate system spanning:
- Boltzmann observers;
- memory and quasi-memory;
- digital copy/restore;
- simulation;
- branching identity;
- observer measure;
- cognitive instability.

That value remains to be demonstrated.

## 10. Concrete next test: FORK-0

Stop refining terminology and classify one case.

At `t0`, hypothetical conscious digital system `A` is snapshotted.

At `t1`, two executions begin from that exact snapshot:

- `A1`: original hardware/environment.
- `A2`: different hardware with a perfect emulation of the same immediate environment.

For the first ten seconds:
- computational transitions are functionally isomorphic;
- accessible autobiographical records are identical;
- outputs are identical;
- neither can distinguish its hardware.

After ten seconds their environments diverge.

At `t1 + 5s`, classify A1 and A2 with respect to:

1. local realization;
2. narrow content;
3. wide content;
4. phenomenology;
5. autobiographical-memory authenticity;
6. numerical identity with pre-fork A;
7. numerical identity with each other;
8. observer-measure counting.

For each classification, state the theory it depends on.

Then answer:

> **Does observer provenance produce any nontrivial result in FORK-0 that standard personal-identity and content theories do not already produce?**

If not, say so.
