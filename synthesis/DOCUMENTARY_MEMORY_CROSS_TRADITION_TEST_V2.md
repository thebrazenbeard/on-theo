## Neutral question

HOW_CAN_AUTHORITATIVE_MEMORY_BE_ENCODED_STABILIZED_RETRIEVED_INTERPRETED_AND_TRANSMITTED_WITHOUT_ASSUMING_ALPHABETIC_PROSE_AS_THE_DEFAULT_DOCUMENT?

## 1. Haudenosaunee — wampum / oral-office memory

Current public evidence supports:
- material belts/strings;
- treaty/title/message/history functions;
- oral interpretation;
- office/community memory;
- recurrent diplomatic and ceremonial renewal.

Subtype:

MATERIAL_MNEMONIC_ORAL_INSTITUTIONAL_DOCUMENT.

Semantic access:
LIVING_INSTITUTIONALLY_INTERPRETED in selected current public contexts.

The material object is not autonomous prose.

## 2. Inca — khipu specialist material records

Secure current evidence supports:
- cord/knot hierarchy;
- numerical/administrative record;
- specialist khipukamayuq;
- historical testimony for broader memory functions;
- only partial present semantic recovery beyond securely decoded numerical use.

Subtype:

MATERIAL_CODED_SPECIALIST_RECORD.

Semantic access:
HIGH_FOR_SELECTED_NUMERIC_ADMINISTRATIVE_FUNCTION;
PARTIAL_OR_LOST_FOR_MUCH_NONNUMERIC_CONTENT.

The surviving object can outlive the interpretive institution.

## 3. Ifá — indexed open oral corpus

Current evidence supports:
- stable 256-odù formal index;
- large open-ended oral verse repertoire;
- trained specialist memorization and interpretation;
- material sign-generation technologies;
- performance connecting precedent to current consultation;
- corpus adaptation without loss of formal index.

Subtype:

INDEXED_OPEN_ORAL_PERFORMATIVE_CORPUS.

Semantic access:
LIVING_DISTRIBUTED_SPECIALIST_INTERPRETATION.

No single material object contains the total corpus.

## 5. Where the "document" lives

The comparison requires separating:

ENCODING_SURFACE
- belt;
- cord/knot;
- generated odù figure.

CONTENT_REPERTOIRE
- orally interpreted treaty/history;
- recorded administrative quantities/categories;
- oral Ifá verse repertoire.

INTERPRETIVE_INSTITUTION
- title holders/community/diplomatic offices;
- khipukamayuq;
- babaláwo/specialist lineages.

RETRIEVAL_EVENT
- treaty recitation/renewal;
- administrative reading;
- divination consultation.

The "document" can therefore be a distributed system rather than an object.

## 6. Semantic recoverability

A key new comparison dimension:

SEMANTIC_RECOVERABILITY_MODEL.

Values observed here:

LIVING_INSTITUTIONAL_READING
- selected wampum.

PARTIAL_DECIPHERMENT_WITH_LOST_CONTEXT
- many surviving khipu.

LIVING_DISTRIBUTED_PERFORMATIVE_READING
- Ifá.

This difference matters more than merely asking whether the medium survives.

## 7. Fixedness

Wampum:
material form can stabilize a remembered relation while oral wording may vary.

Khipu:
material coding can preserve a record while interpretive semantics may become
partially inaccessible.

Ifá:
formal index is stable while verse content is open and distributed.

Therefore:

AUTHORITY != TOTAL_VERBATIM_FIXITY.

## 8. Oral / material false binary

All three cases combine media.

- Wampum requires oral/social interpretation.
- Khipu historically required trained human readers.
- Ifá combines oral corpus with material/sign-generation tools.

Therefore:

ORAL_VS_MATERIAL
is an inadequate top-level opposition.

Better:

MATERIAL_ORAL_PERFORMATIVE_CONFIGURATION.

## 9. Transmission and change

Documentary continuity can persist through:
- institutional renewal;
- specialist apprenticeship;
- changing transcription/documentation;
- material survival;
- repertoire adaptation.

But:

MEDIUM_CONTINUITY != MEANING_CONTINUITY_BY_DEFAULT.

And:

MEANING_CONTINUITY != IDENTICAL_WORDING.

AUTHORITATIVE_MEMORY_CAN_BE_STABILIZED_BY_DISTRIBUTED_SYSTEMS_OF_MATERIAL_FORM_ORAL_REPERTOIRE_SPECIALIST_OFFICE_AND_PERFORMATIVE_RETRIEVAL_AND_THE_SURVIVAL_OF_A_DOCUMENTARY_MEDIUM_DOES_NOT_DETERMINE_HOW_MUCH_OF_ITS_SEMANTICS_REMAIN_ACCESSIBLE.
