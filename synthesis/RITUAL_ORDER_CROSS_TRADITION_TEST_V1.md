# Ritual Order Cross-Tradition Test V1

Status: BOUNDED COMPARISON / NON-CANONICAL

## Purpose

Five of the six currently bound non-Abrahamic lanes now have admitted evidence for `RITUAL_ORDER_MODEL`.

This test asks whether "ritual" is one common mechanism.

It does not assume that it is.

Exact source heads are locked in:
- `synthesis/BOUNDED_NEUTRAL_COMPARISON_MATRIX_V2.yaml`.

## 1. Hindu / Vedic layer

The selected Vedic ritual packet supports an ordered system involving:
- sacred fires;
- spatial arrangement;
- calendrical and daily timing;
- offerings;
- specialist roles;
- sacrificer participation;
- sequence;
- error/expiation rules.

The rite is not just symbolic content.

Correct configuration is itself part of what the source treats as valid ritual performance.

Neutral mechanism class:

`CONFIGURATIONAL_LITURGICAL_ORDER`.

This label is project abstraction, not a Sanskrit category.

## 2. Daoist early religious layer

The selected Celestial Masters layer emphasizes:
- registers;
- petitions;
- confession;
- divine offices;
- authorized religious roles;
- communal/institutional mediation.

Neutral mechanism class:

`BUREAUCRATIC_MEDIATED_RITUAL_ORDER`.

The label is descriptive and does not imply that divine bureaucracy is metaphorical.

## 3. Shinto ritual layer

Engishiki/norito and shrine evidence emphasize:
- authorized ritual speech;
- purity/pollution state;
- calendrical rites;
- offerings;
- shrine/place;
- court and ritual offices.

Neutral mechanism class:

`PURITY_AND_OFFICE_MEDIATED_RITUAL_ORDER`.

This is not reducible to moral guilt, petition, or sacrifice alone.

## 4. Norse material layer

Tissø and mortuary archaeology support:
- structured deposition;
- feasting;
- animal/object placement;
- burial construction;
- multiple ritual loci;
- possible cult structures.

The evidence is primarily material, not a preserved liturgical manual.

Neutral mechanism class:

`MATERIAL_PERFORMATIVE_RITUAL_ORDER`.

The current lane cannot yet recover one universal sequence of words, offices, or meanings.

## 5. Sumerian layer

The deep Sumerian chain supports:
- temple/city institutional ritual;
- offerings;
- divine patronage;
- funerary provisioning;
- monumental and domestic cult contexts;
- administrative participation.

Neutral mechanism class:

`TEMPLE_ADMINISTRATIVE_AND_OFFERING_ORDER`.

This varies by city, period, and context.

## 6. Buddhism

Current status:

`NOT_ADMITTED`.

This means only that the current exact Buddhist source extension has not yet produced a bounded ritual-order packet.

It does not mean Buddhism lacks ritual.

No general knowledge is inserted to fill the cell.

## 7. Cross-tradition result

The five admitted lanes all contain ordered ritual action.

That coarse commonality is real but weak.

At mechanism level the current evidence distinguishes:
- configurational/liturgical order;
- bureaucratic-mediated order;
- purity-and-office-mediated order;
- material-performative order;
- temple-administrative/offering order.

These classes overlap in places.

They are not semantic equivalents.

Therefore:

`ALL_HAVE_RITUAL`
does not entail
`ONE_RITUAL_MECHANISM`.

## 8. Stronger shared structure

A more defensible cross-lane abstraction is:

`RITUAL_VALIDITY_DEPENDS_ON_STRUCTURED_RELATIONS`.

Those relations can include:
- person/office;
- place;
- time;
- material;
- speech;
- sequence;
- purity/status;
- offering;
- institutional authorization.

This is a neutral project-level observation.

It does not identify why ritual is efficacious in any tradition.

## 9. Systems-model consequence

The GOD model can map ritual to:
- protocol;
- permissions;
- state transitions;
- authorized calls;
- boundary conditions.

But that mapping is optional and downstream.

The source evidence does not establish that ancient ritualists were describing computational protocols.

The correct sequence remains:

`SOURCE_RITUAL -> NEUTRAL_RELATIONAL_STRUCTURE -> OPTIONAL_SYSTEMS_ANALOGY`.

## 10. Current conclusion

The ritual comparison strengthens the broader project result:

ON_THEO is finding repeated **problem structures** more readily than one repeated hidden doctrine.

Across these lanes, ritual repeatedly organizes relationships among:
- agents;
- states;
- places;
- materials;
- timing;
- authority.

But the source-specific mechanisms remain distinct.
