# Source-Defined Outcome Narrowing V1

Status: NON-CANONICAL / CHILD OF CLAUSE-DISCRIMINATOR PR #139

## Question

The previous phase found several source-secure cases where religious texts
define exact inputs, errors, repairs, or formal operations.

Which of those cases also has an output narrow enough that a future safe test
could genuinely fail?

## Answer

No current candidate satisfies the entire desired conjunction.

The project now has different candidates occupying different corners of the
design space:

- Hekhalot: strongest exact input brittleness, weak modern outcome/safety;
- Kulārṇava: strong form-error contrasts, outcome too generic;
- Baopuzi: strong written-form contrast, outcome too generic and confounded;
- Sefer ha-Razim: strong failure/repair logic, revelatory output still broad;
- Ifá: weaker input brittleness but strongest safe finite output;
- Neo-Assyrian extispicy: strong finite output plus validity clauses, but literal
  historical procedure is not safe for modern reproduction.

That result is more informative than forcing one winner.

## 1. Outcome precision and input precision are separate axes

The earlier research implicitly favored exotic-looking input structures:

- exact counts;
- unusual phonemes;
- talismanic graphics;
- initiation;
- ritual order.

That was a mistake if the research objective is falsifiability.

A perfectly exact input is scientifically weak when its claimed outcome is:

- siddhi;
- power;
- protection;
- success;
- revelation;
- divine favor.

Those outcomes allow too much interpretive latitude.

Conversely, a less exotic ritual with a binary answer can be scientifically
more useful because:

`MISS = MISS`.

Therefore the matrix now separates:

`INPUT_BRITTLENESS`
from
`OUTPUT_PRECISION`.

## 2. Ifá — strongest safe outcome-precision candidate

Bascom's public description of Ifá includes a specific-alternative stage where
questions can be posed as:

- mutually exclusive alternatives;
- affirmative versus negative propositions;
- yes/no questions.

This is the narrowest safely usable outcome format currently identified.

The reason is not that Ifá is "more likely to be supernatural."

The reason is methodological:

- finite response space;
- public scholarly description;
- low need for semantic grading;
- living practitioner participation can be voluntary and non-invasive;
- ordinary probability models can be frozen;
- a modern hidden target can be held independently.

The major weakness is equally important:

the proposed hidden target is modern.

The source does not say:
"Use this procedure to identify a cryptographically hidden random bit."

Therefore a modern test would be:

`STRUCTURAL_TRANSLATION`,
not
`HISTORICAL_REPLICATION`.

## 3. Ifá null model — do not assume 50/50

Bascom gives an etic probability model for the 256 figures.

A conditional mathematical model was therefore derived for a public binary
seniority-comparison abstraction.

Under the assumptions of:
- two independent uniform draws over 256 ranked figures;
- one consistent seniority convention;
- side determined only by relative rank;
- ties discarded or repeated;

the probabilities are:

`P(tie) = 1/256`.

`P(first senior) = 255/512`.

`P(second senior) = 255/512`.

Conditional on no tie:

`P(each side) = 1/2`.

This is mathematics, not ethnography.

The actual experimental procedure must first survive a null-only calibration
run.

Wrong baseline choice can manufacture an anomaly.

## 4. Neo-Assyrian extispicy — ancient independent comparator

State Archives of Assyria 4 provides an important hostile control.

SAA 4 149 asks whether Esarhaddon should install Sin-nadin-apli in the
Succession Palace.

SAA 4 051 asks whether named enemies will capture Kilman.

The query formularies explicitly request a firm positive answer and favorable
signs.

They also contain detailed clauses instructing the diviner to disregard
possible defects such as:
- ritual impurity;
- defective animal;
- location contamination;
- altered proceedings;
- a jumbled oracle question.

This is an unusually strong historical conjunction:

`PRE-FORMULATED_FINITE_QUESTION + PROCEDURAL_VALIDITY_CONTROLS + POLARIZED_OUTPUT`.

But it has the opposite experimental profile from Ifá:

historically strong;
literally unsuitable for modern reproduction.

Its value is comparative and adversarial.

## 5. Binary output is not exotic

If both Yorùbá Ifá and Neo-Assyrian royal divination can produce finite
alternative answers, binary structure itself is not a rare signature of hidden
architecture.

The ordinary explanation is powerful:

humans frequently face binary decisions.

Questions like:
- should we do this?
- will this happen?
- is this favorable?

naturally invite finite oracle outputs.

Therefore:

`BINARY_DIVINATION = HIGH_EXPERIMENTAL_UTILITY`

while:

`BINARY_DIVINATION = LOW_METAPHYSICAL_SPECIFICITY`.

That is exactly the kind of distinction this project needs.

## 6. Why the strongest brittleness cases are not first experiments

### Hekhalot §§204–205

Excellent historical brittleness:
- exact count;
- explicit prohibition on variation;
- alternate consequence.

Poor first experiment:
- source attaches danger language;
- outcome is not cleanly safe/scoreable;
- literal reproduction is not admitted.

### Kulārṇava 15.55 and 15.57–58

Excellent source-defined correct/defective form contrasts.

Poor first experiment:
- result is generic mantric success/siddhi;
- form differences can overlap linguistic difference;
- exact historical practice is not reducible to one neutral lab variable.

### Baopuzi 19

Excellent written-form preservation/error contrast.

Poor first experiment:
- source outcome is generic benefit/failure/harm;
- practitioner sincerity is also source-relevant.

### Sefer ha-Razim

Excellent failure/recovery logic.

Still weak as first experiment:
- revelatory output is not yet narrowly encoded;
- text is reconstructed from complex witnesses;
- selected procedures are multiparameter.

## 7. The first empirical candidate should be deliberately boring

The methodology now favors a candidate that looks less magical but is easier to
kill.

That means:

- finite answer;
- public procedure;
- transparent null;
- no dangerous historical element;
- no interpretive rescue;
- hidden target independently held;
- response committed before reveal.

Ifá currently fits that methodological profile best.

This is not a truth ranking of traditions.

It is experimental design triage.

## 8. First empirical phase should be calibration, not anomaly hunting

Before any hidden target:

### Phase 0 — procedure freeze

Document:
- exact public procedure;
- operator qualifications;
- A/B coding;
- invalid/tie handling;
- number of casts;
- re-cast rule;
- stop rule.

### Phase 1 — null-only calibration

Run the procedure with no meaningful hidden target.

Measure:
- A/B frequency;
- tie/invalid rate;
- serial dependence;
- operator dependence;
- drift over time.

The purpose is not to contact anything.

It is to determine what the apparatus does under the ordinary model.

### Phase 2 — target-blind preregistration

Only if Phase 1 supports a stable null:
- freeze target-generation process;
- freeze primary endpoint;
- freeze sample size;
- freeze exclusion rules;
- freeze analysis;
- hash/archive protocol.

### Phase 3 — hidden-target test

Target remains inaccessible until response commitment.

Each trial is:
- target generated or held independently;
- response committed;
- target revealed;
- mechanical hit/miss score.

No semantic rescue.

### Phase 4 — fresh holdout

Any exploratory redesign requires a new untouched holdout.

## 9. What a positive result would mean

A statistically credible result after calibration, blinding, holdout, and
independent replication would support only:

`ANOMALOUS_INFORMATION_RELATIVE_TO_TESTED_CHANNELS`.

It would not identify:
- Òrúnmìlà;
- a deity;
- an angel;
- a simulator;
- a hidden architecture;
- one religion as true.

Source identity is a separate experiment.

## 10. What a null result would mean

A clean null would weaken:

`THIS_MODERN_IFA_BINARY_TRANSLATION_AS_AN_ANOMALOUS_INFORMATION_CHANNEL`.

It would not falsify:
- all Ifá;
- all divination;
- all religious experience;
- all hidden-interface hypotheses.

But the project is prohibited from rescuing the failed candidate by silently
adding:
- extra rituals;
- secret variables;
- another religion;
- different timing;
- a new target class.

A new candidate must earn admission independently.

## 12. Current frontier

The historical search for narrow outcomes has succeeded enough to choose a
methodological candidate.

The next frontier is therefore not another religious corpus sweep.

It is:

`PUBLIC_BINARY_PROCEDURE_CALIBRATION_DESIGN`.

The goal is to specify a safe, respectful, preregisterable Phase-1 calibration
that tests the ordinary null before any anomalous-information trial exists.
