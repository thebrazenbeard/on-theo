## Outcome precision taxonomy

### Highest value
- binary;
- finite discrete;
- specific hidden fact;
- specific future event.

### Medium value
- fixed answer table with interpretive mapping;
- bounded category response.

### Low value
- generic revelation;
- generic siddhi;
- generic protection;
- generic power;
- subjective intensity.

This is not a truth ranking.

It is an experimental discriminability ranking.

## Result 1 — input brittleness and output precision are independent

The strongest input-brittleness cases are not the strongest experimental
candidates.

Examples:

- Hekhalot exact count:
  high input specificity, low safe outcome scoreability.
- Kulārṇavatantra form defects:
  high input specificity, generic siddhi endpoint.
- Baopuzi copy errors:
  high written-form specificity, generic benefit/harm endpoint.

Conversely:

- Ifá:
  weaker source-defined correct/incorrect ritual contrast, but very narrow
  yes/no/alternative output.
- Neo-Assyrian extispicy:
  strong finite oracle output, but no safe literal modern procedure.

Therefore:

`INPUT_BRITTLENESS_SCORE != OUTCOME_PRECISION_SCORE`.

This must remain a permanent matrix distinction.

## Result 2 — Ifá is the current safe prospective lead

Bascom's public description of Ifá permits:
- yes/no questions;
- mutually exclusive alternatives;
- finite choices.

That gives:
- mechanical scoring;
- preserved misses;
- explicit statistical null competition.

Current status:

`PROVISIONAL_FIRST_EMPIRICAL_METHOD_CANDIDATE`.

Not:

`PROVEN_ANOMALY`.

Not even:

`READY_TO_RUN`.

The exact procedure's null distribution remains a gate.

## Result 3 — Neo-Assyrian extispicy is the strongest ancient finite-output comparator

SAA 04 query/report texts show:
- pre-formulated questions;
- favorable/positive answer requests;
- favorable/unfavorable reports.

This confirms that finite-output divine consultation has ancient documentary
precedent.

But the source family is also a hostile control.

Selected query formulae explicitly ask the deity to disregard possible ritual
or formulation faults.

Therefore the same corpus gives:

`FINITE_OUTPUT`
plus
`ERROR_TOLERANCE`.

That is inconsistent with a crude universal brittle-parser model.

## Result 4 — PGM strengthens recipe structure more than outcome precision

PGM IV and related divination material show explicit attempts to obtain answers.

The Homeromanteion supplies a finite 216-output mechanical map.

But:
- free-form revelation remains open-ended;
- Homeric verse interpretation remains flexible.

Therefore:

`FINITE_MECHANICAL_SELECTION != FINITE_SEMANTIC_PREDICTION`.

PGM remains a top source-acquisition frontier for low-semantic operative form,
but not the current best anomaly-test endpoint.

## Result 5 — highly precise historical outcomes can still be ethically unusable

Selected Sefer ha-Razim material contains very specific fate/death timing
claims.

That increases historical outcome precision.

It does not increase modern experimental priority.

Therefore:

`OUTCOME_PRECISION != ETHICAL_TESTABILITY`.

This guard prevents the project from treating dangerous or intrusive predictions
as scientifically desirable merely because they are easy to score.

## Experimental implication

Do not combine the best input from one religion with the best output from
another.

That would manufacture a synthetic ritual with no historical source.

The first test must stay inside one candidate family.

This is why Ifá currently leads despite having less spectacular ritual
brittleness.

Its output format is empirically cleaner.
