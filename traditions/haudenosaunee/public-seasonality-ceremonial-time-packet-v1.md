# Haudenosaunee Public Seasonality and Ceremonial Time Packet V1

Status: PUBLIC CEREMONIAL-TIME CONTROL / NATION-SPECIFIC / NON-CANONICAL

## Purpose

Bind a living Haudenosaunee sacred-time layer from current nation-controlled
public sources without converting Oneida public ceremonial descriptions into a
single pan-Haudenosaunee calendar.

Core rule:

ONEIDA_PUBLIC_CEREMONIAL_CYCLE != ONE_IDENTICAL_HAUDENOSAUNEE_CALENDAR.

## 1. Current Oneida public source

The Oneida Nation publicly states that ceremonies follow:
- the cycle of the seasons;
- agriculture;
- the moon;
- recurring ecological events.

Faithkeepers determine timing through observation of:
- agricultural conditions;
- lunar cycles;
- seasonal changes.

Evidence class:
MODERN TRADITION / CURRENT NATION SELF-DESCRIPTION /
PUBLIC CEREMONIAL CATEGORY.

Current axis:

SACRED_TIME_CALENDAR_MODEL =
BOUNDED_ONEIDA_SEASONAL_ECOLOGICAL_LAYER.

## 2. Sacred time is event-responsive, not merely date-fixed

The public Oneida material indicates that at least some ceremonial timing is
responsive to:
- first thunder;
- sap flow;
- planting;
- berry ripening;
- bean/corn maturation;
- harvest;
- frost/ground conditions;
- lunar observation.

Current proposition:

RITUAL_TIME_CAN_BE_ECOLOGICALLY_OBSERVED_AND_OFFICE_INTERPRETED.

This differs from:
- a fixed written annual calendar;
- a purely astronomical table;
- an unchanging numerical cycle.

## 3. Faithkeeper timing authority

- observing conditions;

- preparing/maintaining Longhouse ceremonial life.

## 4. Midwinter / renewal

Oneida public sources describe Midwinter as:
- tied to the new-year moon;
- a period of renewing responsibilities;
- a ceremonial renewal cycle.

Current classification:

## 5. Maple, planting, berry, bean, corn, harvest cycles

Public Oneida descriptions show multiple ceremonies linked to:
- maple season;
- seed/planting;
- strawberry/first fruit;
- beans;
- green corn;
- harvest.

Current result:

CEREMONIAL_TIME_IS_RELATIONALLY_LINKED_TO_FOOD_PLANTS_AND_AGRICULTURAL_LIFE.

This supports:

RELATIONAL_ORDER_MODEL.

- plants are interchangeable recipients;
- one offering mechanism;
- one agricultural deity system.

## 6. Sun and Moon ceremonial categories

Oneida publicly describes separate thanksgiving ceremonies honoring:
- Sun/day/light;
- Moon/night/light.

Current result:

CELESTIAL_CYCLES_ARE_PART_OF_PUBLIC_ONEIDA_CEREMONIAL_TIME.

This supports:
SACRED_TIME_CALENDAR_MODEL.

It does not support:

## 7. Ancestor timing

The public Community Death Feast occurs twice annually:
- spring after frost leaves the ground;
- fall after harvest.

Current consequence:

MORTUARY_RELATIONSHIP_MODEL
and
SACRED_TIME_CALENDAR_MODEL

intersect in a current Oneida public layer.

This is stronger than treating ancestor relation as timeless/atemporal.
