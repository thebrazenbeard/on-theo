# Mesopotamian Traditions — Neo-Assyrian Extispicy Binary Outcome Packet V1

Status: NEO-ASSYRIAN ROYAL DIVINATION / PRIMARY TEXT + CRITICAL EDITION CONTROL / NON-CANONICAL

## Purpose

Test whether an independent ancient divinatory tradition preserves
prospectively narrow, effectively binary oracle questions.

Yes.

Neo-Assyrian royal extispicy queries to Šamaš routinely formulate concrete
questions such as:

- will a named enemy capture a named place?
- should the king undertake a specified action?
- should a named prince be installed in a specified office?

The ritual asks for a firm positive answer and favorable signs if the proposition
is divinely approved.

This supplies a historically explicit finite outcome format.

## Outcome precision

The relevant output is not generic "divine guidance."

It is a response to a pre-formulated proposition.

At the question level:

`PROPOSITION = TRUE/FAVORED`
versus
`PROPOSITION = NOT_CONFIRMED/UNFAVORED`.

This is close to a binary oracle structure.

The exact historical interpretation involved omen aggregation and expert
judgment, so the answer must not be simplified into a modern electronic
yes/no bit without qualification.

Still, compared with generic revelation or siddhi, the outcome is highly
prospectively scoreable.

## Firm positive answer

SAA 4 repeatedly asks Šamaš for an Akkadian `annu kīnu` / firm positive
answer.

This is a strong historical result because the desired response polarity is
specified before the divinatory observation.

It reduces one class of post-hoc ambiguity:

the question is not invented after the omen is seen.

## Favorable/unfavorable omen structure

The corpus records favorable and unfavorable extispicy signs and can summarize
or weigh them in reaching a decision.

This supports:

`FINITE_POLARITY_OUTPUT`.

But:

`FINITE_POLARITY_OUTPUT != SIMPLE_UNWEIGHTED_COIN_FLIP`.

The historical diagnostic procedure may contain:
- multiple anatomical signs;
- weighting rules;
- expert interpretation;
- invalidating/contamination clauses;
- repeat or replacement procedures.

The null distribution for any modern abstraction must therefore be derived from
the exact abstracted rule, not assumed from the ancient label "yes/no."

## Ritual contamination and invalidation clauses

The SAA 4 queries contain explicit "disregard" clauses dealing with possible
sources of ritual contamination or procedural defect, including:

- defective sacrificial animal;
- impurity at the ritual location;
- practitioner impurity;
- formulation problems;
- alteration or jumbling of the oracle query.

This is important to the larger ritual-interface project.

The same source family combines:

`NARROW_OUTCOME`
+
`PROCEDURAL_VALIDITY_CONTROLS`.

Historically, that makes Neo-Assyrian extispicy a stronger comparison case than
a divination system with a crisp answer but no documented error model.

Ifá and Neo-Assyrian extispicy arise in very different historical settings.

No direct transmission claim is made here.

But even if historically independent, the recurrence can be explained by a
simple convergent problem:

decision makers often need a finite answer to a finite question.

This strongly supports:

`CONVERGENT_DECISION_UTILITY`

as an ordinary rival.

Thus:

`SAFE_BINARY_ABSTRACTION != EXTISPICY_REPLICATION`.

## Experimental relevance

This source family is useful in two ways.

### 1. Outcome-precision control

It proves that precise yes/no-style religious outputs can emerge for ordinary
decision-making reasons.

### 2. Procedural-validity control

It provides historical clauses where practitioners explicitly tried to neutralize
possible contamination or procedural error.

This lets the project compare:
- Ifá binary outcome;
- Neo-Assyrian binary outcome;
- Hekhalot exact-count brittleness;
- Kulārṇava form-error brittleness;
- Sefer ha-Razim failure/repair logic.

These are different axes.
