# Gauquelin Mars Effect — Controversy Map V1

Status: DISPUTED / REPLICATION LEDGER NOT YET COMPLETE

## Claim

Michel and Françoise Gauquelin reported that highly eminent athletes were born with Mars in specified sectors of the diurnal circle more often than expected.

This is not the same proposition as:
- Mars sign predicts athleticism;
- Mars causes athletic performance;
- ordinary natal astrology is validated;
- planetary gravity causes personality.

## Why the case matters

The Mars-effect literature is methodologically valuable because it forces separation of:

1. an observed statistical deviation;
2. subject-selection rules;
3. expected-rate calculation;
4. birth-time quality;
5. replication;
6. causal interpretation.

A result can be statistically unusual without supplying a mechanism.

## Evidence state

The branch currently classifies the effect as DISPUTED.

Reasons:
- Gauquelin reported repeated positive samples;
- skeptical committees conducted independent or semi-independent tests;
- some tests were described as null;
- later analysts disputed sample-selection and expectancy rules;
- “eminence” criteria became a major source of disagreement;
- later birth-record practices may differ from earlier records.

Sources for the controversy:
- Suitbert Ertel, later Mars-effect reanalyses;
- Comité Para replication debate;
- CFEPP replication/reanalysis debate;
- contemporary skeptical and astrology-research literature.

One astrology-research account of Ertel's reanalysis:
https://www.astrology-research.net/2022/10/05/is-there-no-mars-effect/

Historical skeptical discussion:
https://skepticalinquirer.org/

## Strong claim ceiling

At present the repository should not state:

MARS_EFFECT = PROVEN.

It should also avoid:

MARS_EFFECT = DEFINITIVELY_FRAUDULENT_OR_NONEXISTENT.

The correct current repository status is:

A REPORTED SMALL STATISTICAL EFFECT WITH A LONG, METHOD-SENSITIVE, CONTESTED REPLICATION HISTORY.

## Relevance to conventional astrology

Even if a Mars-sector effect were independently confirmed, it would not directly validate:
- zodiac signs;
- houses as traditionally interpreted;
- aspects;
- rulership;
- synastry;
- horary;
- electional astrology.

The variable is a diurnal-sector position tied to professional eminence.

That proposition requires its own theory.

## Relevance to the simulation hypothesis

The Mars-effect controversy is useful as a template, not evidence for simulation.

A hidden common-cause model could in principle produce:
- a tiny correlation;
- population specificity;
- profession specificity;
- no obvious physical mechanism.

But so could:
- selection artifacts;
- record artifacts;
- demographic structure;
- multiple testing;
- post hoc thresholding;
- ordinary unknown confounding.

Therefore:

UNEXPLAINED_CORRELATION != CONTROLLER_SIGNAL.

## Required replication ledger

Before upgrading or downgrading the claim, create one record per dataset:

- dataset owner;
- collection dates;
- countries;
- sport definition;
- eminence criterion;
- birth-time source;
- exclusion rules;
- Mars-sector definition;
- expected rate;
- observed count;
- statistical method;
- preregistered or post hoc;
- independent from Gauquelin;
- later corrections;
- data availability.

Only then compare results.

## Current research value

The controversy is a good stress test for the branch's epistemic discipline because both believers and skeptics have incentives to compress a complicated record into a slogan.

The repository should refuse both slogans.
