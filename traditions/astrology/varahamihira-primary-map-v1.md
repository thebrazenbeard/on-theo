# Varāhamihira — Primary Text Map V1

Status: PRIMARY-TEXT EXTRACTION STARTED

## Source identity

Varāhamihira, sixth century CE, is a major Sanskrit astral-science author.

This file separates:
- Bṛhat Jātaka;
- Bṛhat Saṃhitā.

They are not interchangeable works.

## Bṛhat Jātaka — horoscopic architecture

Accessible Sanskrit/English:
https://www.wisdomlib.org/hinduism/book/brihat-jataka-by-varahamihira-sanskrit-english

Public-domain historical translation:
N. Chidambaram Iyer, 1885
https://wellcomecollection.org/works/afmgm695

The work has 28 chapters in the accessible recension/translation.

Technical topics include:
- rāśis/signs;
- planetary natures;
- conception and birth;
- longevity;
- daśā/antardaśā timing;
- aṣṭakavarga;
- profession;
- rāja-yoga;
- planetary combinations;
- nakṣatra results;
- aspects/dṛṣṭi;
- houses/bhāvas;
- misfortune;
- female horoscopy;
- death;
- lost/unknown horoscopes;
- drekkāṇa/decanate forms.

## Greek/Yavana intellectual memory

Bṛhat Jātaka 11.1 explicitly refers to Yavanas in connection with an expanded enumeration of combinations.

Source:
https://www.wisdomlib.org/hinduism/book/brihat-jataka-by-varahamihira-sanskrit-english/d/doc1501742.html

This is direct textual evidence that Varāhamihira's intellectual horizon included Yavana authorities.

Guard:

YAVANA_REFERENCE != PROOF_THAT_EVERY_TECHNIQUE_IS_GREEK.

Each doctrine still needs separate transmission evidence.

## Lost horoscope reconstruction

Chapter 26 concerns lost/unknown horoscopes.

Accessible text:
https://www.wisdomlib.org/hinduism/book/brihat-jataka-by-varahamihira-sanskrit-english/d/doc1501561.html

The chapter attempts to infer unknown birth information using the state at the time of inquiry.

This is technically important because it shows that the source is not limited to ordinary known-time natal interpretation.

Research relation:
later praśna/interrogational and rectification traditions require independent chronology before equivalence is asserted.

## Bṛhat Saṃhitā — broader jyotiṣa

Accessible English:
https://www.wisdomlib.org/hinduism/book/brihat-samhita

Chapter 2 defines the qualified jyotiṣaka as versed in three broad domains:
- Saṃhitā;
- astronomy;
- horoscopy.

Source:
https://www.wisdomlib.org/hinduism/book/brihat-samhita/d/doc226718.html

This provides a primary-text anchor for the branch distinction:

JYOTIṢA > NATAL_ASTROLOGY.

## Bṛhat Saṃhitā subject range

The work includes extensive material on:
- Sun;
- Moon;
- Rāhu/eclipses;
- Mars, Mercury, Jupiter, Venus, Saturn;
- planetary conjunctions;
- stellar phenomena;
- weather;
- omens;
- architecture;
- agriculture;
- ritual and worldly prognostication.

Therefore “astrology” is an imperfect modern umbrella for the whole work.

## Astronomy/astrology interface

Varāhamihira's texts repeatedly rely on computational/observational celestial knowledge to support prognostication.

That does not mean the categories:
MODERN_ASTRONOMY
and
MODERN_ASTROLOGY

map cleanly onto sixth-century Sanskrit disciplinary boundaries.

## Comparison with simulation hypothesis

Varāhamihira is historically useful because the same intellectual corpus combines:
- calculable celestial state;
- omen/prognostic interpretation;
- individual horoscopy.

This is exactly the kind of system where:

STATE_ESTIMATION
and
STATE_INTERPRETATION

must be separated.

But nothing in the texts supports simulation theory as an ancient intended meaning.
