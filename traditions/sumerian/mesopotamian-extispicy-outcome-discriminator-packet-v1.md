## Purpose

Test whether an independent ancient divinatory system also uses narrowly
scoreable, pre-formulated oracle questions.

Yes.

Neo-Assyrian extispicy queries preserved in SAA 4 / ORACC include explicit
questions of the form:

- will event X occur?
- will a city be captured?
- should the king undertake action Y?
- is a given political/military outcome decreed?

The ritual framework asks Šamaš/Adad for a favorable or unfavorable oracle and
can explicitly request a "firm positive answer."

This gives:

`FINITE_OR_DIRECTIONAL_ORACLE_OUTCOME`.

## Oracle structure and probability

Mesopotamian extispicy does not simply read one binary mark.

The diviner examines multiple anatomical features whose omen values are combined
within a learned interpretive system.

Therefore:

`BINARY_QUERY != SIMPLE_FAIR_COIN_OUTPUT`.

A modern chance model requires reconstruction of the actual decision rule.

This parallels the Ifá warning:

`FINITE_OUTPUT != 0.5_NULL_BY_DEFAULT`.

## Outcome precision

The strongest methodological feature is that many queries concern a definite
future or political event.

Examples include:
- whether a campaign/action should be undertaken;
- whether a named city will fall;
- whether rebellion is decreed/confirmed.

These are prospectively scoreable in principle.

However the historical questions are embedded in royal politics and warfare.

Modern literal reproduction is neither necessary nor appropriate.

## Input precision versus outcome precision

This system scores:

- outcome precision: HIGH;
- source-defined ritual procedure: HIGH;
- source-defined binary/directional interpretation: HIGH;
- safe literal reproducibility: LOW;
- modern structural abstraction: POSSIBLE;
- empirical anomalous effect: NONE ESTABLISHED.

## Critical hostile result

The existence of another independent historical system with crisp yes/no or
favorable/unfavorable outputs means:

`BINARY_DIVINATION != LOW_BASE_RATE_SIGNATURE_OF_ONE_HIDDEN_INTERFACE`.

Humans building decision systems naturally benefit from finite answers.

Therefore binary scoreability is valuable experimentally but weak evidence for
shared exotic mechanism.

## Safety boundary

Historical extispicy involved animal sacrifice.

No modern experiment in this research program reproduces that.

Any modern comparison is structural only:
- finite pre-formulated question;
- hidden or future target;
- fixed scoring;
- harmless random or symbolic input.

That would not be a test of Mesopotamian extispicy efficacy.

## Claim ceiling

`NEO_ASSYRIAN_EXTISPICY_PRESERVES_PRE_FORMULATED_CONCRETE_ORACLE_QUESTIONS`.
