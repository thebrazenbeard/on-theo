# Daoism — Yao Boduo Stele Contact Control V1

Status: EPIGRAPHIC / MATERIAL CONTACT LOCATOR / NON-CANONICAL

## 1. Object anchor

The Yao Boduo stele is dated:

`496 CE`

Northern Wei, Taihe 20.

Modern scholarship treats it as the earliest extant Daoist stele / among the earliest secure Daoist image-stela evidence.

The donor is identified as Yao Boduo.

Useful current object-level scholarship:
https://www.mdpi.com/2077-1444/17/3/369

Classic interpretation:
Stephen R. Bokenkamp, "The Yao Boduo Stele as Evidence for the 'Dao-Buddhism' of the Early Lingbao Scriptures," *Cahiers d'Extrême-Asie* 9 (1996), 55–67.
https://www.persee.fr/doc/asie_0766-1177_1996_num_9_1_1110

## 2. Daoist identity is not inferred from Buddhist-looking form alone

The inscription identifies Daoist religious figures and a Daoist devotional context.

Modern object study notes:
- Daoist donor identity;
- veneration of Laozi/Laojun-related figures;
- Zhang Ling / Celestial Masters associations;
- scriptural transmission themes.

Therefore:

`DAOIST_RELIGIOUS_IDENTITY = MATERIAL_EPIGRAPHICALLY_GROUNDED`.

The stele should not be classified as simply "Buddhist" because it uses forms or concepts also found in Buddhist religious culture.

## 3. Buddhist-contact features

Modern studies identify Buddhist-associated religious language and forms within the stele's program.

Examples discussed in scholarship include:
- rebirth-related language;
- "three evil paths" / release formulations;
- devotional image-making forms;
- salvation language;
- visual conventions shared with Buddhist statuary.

### Evidence classification

The physical inscription/image is:

`EPIGRAPHIC_EVIDENCE + MATERIAL_EVIDENCE`.

The identification of particular features as Buddhist-derived is:

`SCHOLARLY_INTERPRETATION`.

## 4. Huahu / conversion-of-barbarians dimension

The stele's inscriptional program also engages Laozi-converts-the-barbarians themes in modern readings.

This is historically useful because it combines:
- Daoist self-definition;
- contact with Buddhist categories/forms;
- a Daoist claim of precedence or encompassing authority.

### Guard

`HUAHU_REFERENCE`
!=
`HISTORICAL_EVIDENCE_THAT_LAOZI_TAUGHT_BUDDHISM`.

It is evidence for Daoist religious self-positioning under conditions of Buddhist contact.

## 5. Why this object matters for ON_THEO

The stele demonstrates that contact/reinterpretation need not be purely textual.

A single dated object can preserve:
- donor identity;
- iconography;
- inscription;
- doctrinal vocabulary;
- ritual aspiration;
- polemical positioning.

This supports:

`MATERIAL_HYBRIDIZATION_WITH_RETAINED_TRADITIONAL_IDENTITY`.

The adjective "hybrid" is analytical and should not imply that participants lacked meaningful religious distinctions.

## 6. Positive contact claim

Current bounded proposition:

> By 496 CE, a securely Daoist devotional monument can use religious language,
> visual forms, and salvation structures that scholarship associates with
> Buddhist contact while remaining explicitly Daoist in patronage and identity.

This is stronger than:
- generic similarity;
- modern retrospective syncretism.

It is weaker than:
- proof that every feature derives from a single Buddhist source;
- proof that Daoist and Buddhist categories had become identical.
