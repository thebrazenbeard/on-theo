# Inca Huaca / Ceque Sacred-Land Packet V1

Status: CUSCO IMPERIAL RITUAL-LANDSCAPE CONTROL / NON-CANONICAL

## Purpose

Bind the Cusco huaca/ceque system as a source-controlled sacred-land,
institutional and social-order system without treating it as universal Andean
geography.

## 1. Scale and structure

Current historical/archaeological synthesis describes the Cusco ceque system as:
- more than 328 huacas;
- approximately forty-two ceques;
- pathways radiating from the Temple of the Sun / central Cusco;
- a network extending through the Cusco Valley.

Evidence:
HISTORICAL RECONSTRUCTION + ARCHAEOLOGICAL TESTING.

Current axis:

SACRED_LAND_PLACE_MODEL =
BOUNDED_CUSCO_IMPERIAL_RITUAL_LANDSCAPE.

## 2. Huaca diversity

Huacas in the Cusco system can include:
- caves;
- boulders;
- springs;
- mountaintops;
- houses;
- fountains;
- canals;
- other sacred features.

Therefore:

HUACA != ONE_MATERIAL_OBJECT_TYPE.

And:

HUACA != GENERIC_GOD.

The category is relational/contextual and source-dependent.
