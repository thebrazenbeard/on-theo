# Inca Khipu Documentary-Memory Packet V1

Status: MATERIAL-DOCUMENTARY / SEMANTIC-CEILING CONTROL / NON-CANONICAL

## Purpose

Bind khipu as an Inca/Andean documentary technology without forcing it into the
binary categories "mere accounting" or "fully deciphered writing."

Core rule:

KHIPU_RECORDING != ALPHABETIC_WRITING.

A second rule:

NUMERICAL_DECIPHERMENT != GENERAL_SEMANTIC_DECIPHERMENT.

## 1. Secure numerical/administrative function

Current scholarship securely supports khipu use for:
- decimal numerical recording;
- censuses;
- tribute/accounting;
- inventories;
- administrative records;
- state/provincial information management.

Current axis:

DOCUMENTARY_MEMORY_MODEL =
BOUNDED_ADMINISTRATIVE_KHIPU.

INSTITUTIONALIZATION_MODEL =
BOUNDED_KHIPUKAMAYUQ_RECORD_SYSTEM.

## 2. Khipukamayuq specialists

Colonial sources and modern scholarship identify specialized khipu record
keepers.

Current proposition:

DOCUMENTARY_AUTHORITY_WAS_SPECIALIZED.

This supports:
- institutionalization;
- knowledge/disclosure;
- administrative authority.

It does not define a religious office.

## 3. Material encoding complexity

Khipu encode information through combinations of:
- cord hierarchy;
- knot type;
- knot position;
- number;
- color;
- spin/ply direction;
- attachment;
- other structural/material properties.

A 2026 mathematical-knot study emphasizes that some visually distinct knot
forms are topologically equivalent and that knot variation can affect encoding
analysis.

Current project result:

KHIPU_INTERPRETATION_REQUIRES_MATERIAL_STRUCTURAL_CONTROL.

## 4. Narrative/historical claims

Colonial testimony states that khipu specialists could preserve/recount:
- dynastic histories;
- events;
- non-numerical information.

Modern research on "khipu historiography" studies colonial texts said to derive
from khipu records.

But surviving pre-Hispanic khipus cannot currently be generally read as
continuous narrative texts.

Current status:

NON_NUMERICAL_NARRATIVE_CAPACITY =
STRONG_HISTORICAL_CLAIM / PARTIAL_SEMANTIC_RECOVERY.

## 5. Khipu as source behind colonial text

Some colonial narratives claim khipu-based information.

Therefore:

COLONIAL_TEXT_USING_KHIPU_SOURCE
!=
DIRECT_TRANSCRIPTION_OF_SURVIVING_KHIPU.

Required chain:
- colonial author/interviewer;
- khipukamayuq or source community;
- khipu record;
- oral explanation;
- alphabetic recording.

This is multi-stage mediation.

## 6. Colonial and post-Inca khipu continuity

Khipu and hybrid khipu-board practices continued after conquest in selected
Andean communities.

Current scholarship documents:
- colonial khipu;
- hybrid alphabetic/khipu boards;
- twentieth-century ritual/community uses in selected locations.

Current axis:

CONTINUITY_MODEL =
PARTIAL_DOCUMENTARY_TECHNOLOGY_WITH_TRANSFORMATION.

This is not:
unchanged Inca state bureaucracy.

## 7. Knowledge/disclosure

Khipu support a bounded knowledge axis through:
- specialist production;
- specialist reading/interpretation;
- official records;
- oral-material integration.

Current classification:

KNOWLEDGE_OR_DISCLOSURE_MODEL =
BOUNDED_DOCUMENTARY_SPECIALIST_LAYER.

Religious revelation/disclosure is not established from khipu alone.

## 8. Documentary-memory schema

Khipu strongly support promotion of:

DOCUMENTARY_MEMORY_MODEL.

Comparative relevance:
- Haudenosaunee wampum;
- Mesoamerican pictorial manuscripts;
- alphabetic manuscripts;
- oral tradition;
- khipu.

The neutral question is not:
"Did they have writing?"

It is:
"How was authoritative information stabilized, retrieved, embodied and
transmitted?"

## 9. Religious-theology hold

No surviving khipu is used in V1 to establish:
- deity names;
- cosmogony;
- prayers;
- doctrinal propositions;
- ritual scripts.

Therefore:

PRIMARY_KHIPU_THEOLOGICAL_PROPOSITION =
NOT_ADMITTED.
