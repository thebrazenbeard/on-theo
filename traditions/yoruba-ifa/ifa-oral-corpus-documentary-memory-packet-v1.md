# Ifá Oral Corpus / Documentary Memory Packet V1

Status: ORAL-LITERARY / DIVINATORY-DOCUMENTARY CONTROL / NON-CANONICAL

## Purpose

Bind Ifá as a structured oral and material knowledge system without forcing it
into the categories "scripture," "mere folklore," or "unfixed memory."

Core rule:

ORAL_CORPUS != TEXTUAL_DEFICIT.

A second rule:

STRUCTURED_INDEX != CLOSED_CONTENT.

## 1. Formal sign architecture

Public scholarly and UNESCO descriptions support a formal sign system that
generates 256 odù/figures from a sixteen-sign binary structure.

Current result:

IFA_FORMAL_INDEX =
BOUNDED_256_FIGURE_ARCHITECTURE.

This is a strong documentary-memory feature because the consultation does not
select an arbitrary story. A generated sign maps the session into a structured
corpus domain.

## 2. Verse corpus

Scholarly descriptions characterize the corpus as:
- very large;
- orally transmitted;
- associated with the odù structure;
- composed of verses/narratives/proverbs/precedents;
- interpreted by trained specialists;
- not fixed in a final total verse count.

Current result:

IFA_CORPUS =
STRUCTURED_OPEN_ORAL_LITERATURE.

## 3. Fixed structure / open performance

The combination is analytically important:

FIXED_OR_STABLE_256_ODÙ_INDEX
+
OPEN_ADAPTIVE_VERSE_REPERTOIRE.

This differs from:
- one manuscript canon;
- a memorized fixed liturgy;
- unstructured improvisation.

Current new documentary-memory subtype:

INDEXED_OPEN_ORAL_CORPUS.

## 4. Precedent logic

Karin Barber's description emphasizes that Ifá verses commonly present:
- an antecedent divination;
- a client/problem;
- advice or prescribed action;
- subsequent outcome.

Current result:

IFA_MEMORY_CAN_BE_CASE_BASED_AND_PRECEDENTIAL.

This supports comparison with:
- legal precedent;
- divinatory case literature;
- narrative exempla;
- oracle corpora.

It does not mean Ifá is simply a legal system.

## 5. Performance is part of the record

The meaningful unit is not only:
"verse text."

It includes:
- generated odù;
- specialist selection/recitation;
- interpretation;
- current client/situation;
- prescribed response.

Therefore:

IFA_DOCUMENT =
MATERIAL_SIGN + MEMORY + PERFORMANCE + INTERPRETATION.

This is a stronger model than:
ORAL_TEXT_AS_TRANSCRIPT.

## 6. Material memory technology

Public museum evidence documents:
- ọ̀pọ́n Ifá trays;
- ikin palm nuts;
- divination chains;
- containers;
- tappers.

These objects:
- participate in sign generation;
- organize practice;
- materialize specialist authority;
- preserve iconographic variation.

Current classification:

MATERIAL_DIVINATION_TECHNOLOGY =
DOCUMENTARY_PRACTICE_COMPONENT.

## 7. Transmission

UNESCO safeguarding materials explicitly emphasize:
- intergenerational transmission;
- peer/specialist teaching;
- training of Ifá priests;
- preservation/documentation of verses.

Current axis:

KNOWLEDGE_GOVERNANCE_DIMENSION =
BOUNDED_SPECIALIST_INTERGENERATIONAL.

This is not a claim that all Ifá knowledge is secret.

It does establish:
SPECIALIST_TRANSMISSION_IS_INSTITUTIONAL.

## 8. Adaptation

Barber describes the corpus as capable of absorbing new material while
preserving strong formal structure.

Current result:

TRADITIONAL_AUTHORITY
CAN_COEXIST_WITH
CONTENT_ADAPTATION.

This is a major continuity control.

Therefore:

CHANGE != LOSS_OF_TRADITION_BY_DEFAULT.

## 9. Documentation and transcription

Modern projects transcribe, publish and digitize portions of Ifá.

These create:
- written witnesses;
- editions;
- archives;
- educational resources.

But:

TRANSCRIPTION != THE_ORAL_CORPUS_ITSELF.

Each modern edition is:
ONE_MEDIATED_WITNESS_TO_PERFORMED_TRADITION.

## 10. Public/sacred boundary

The project can compare:
- structural corpus form;
- specialist roles;
- transmission;
- material sign technology;
- public philosophical themes.

It does not need:
- exhaustive verse reproduction;
- unauthorized ritual detail;
- claims that a public transcription exhausts specialist knowledge.

## 11. Comparison pressure

Ifá materially expands DOCUMENTARY_MEMORY_MODEL.

Existing admitted controls include:
- Haudenosaunee wampum;
- Inca khipu.

Ifá adds:

INDEXED_PERFORMED_ORAL_CORPUS.

This shows documentary memory can be:
- materially encoded;
- orally memorized;
- performatively retrieved;
- formally indexed;
- specialist interpreted.

No one medium is primary by definition.
