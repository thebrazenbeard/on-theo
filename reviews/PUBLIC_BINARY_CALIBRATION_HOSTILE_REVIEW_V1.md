## Attack 1 — You can fake an anomaly with the wrong null

If the apparatus is biased and you score it against 50/50, you can manufacture
statistical significance.

Repair:
calibrate first.

## Attack 2 — "256 figures are uniform" does not prove the final binary output is uniform

The binary stage can contain:
- ranking rules;
- tie rules;
- recasts;
- hand/side mapping;
- operator handling;
- procedural variants.

Repair:
derive the null for the exact frozen implementation and confirm it empirically.

## Attack 3 — A stable operator bias is boring, not paranormal

If one operator produces A at 55% and another at 48%, first suspect mechanics,
habit, coding, or physical handling.

Do not rename human variation "authorization."

## Attack 4 — Serial dependence will inflate naive evidence

If A tends to follow A, N trials are not N independent pieces of evidence.

Repair:
test transitions and runs before target phase.

## Attack 5 — Calibration data must remain spiritually meaningless

Do not secretly assign meaning to long runs, strange sessions, or operator
differences after seeing them.

This phase has no target and no message.

If the team starts interpreting patterns anyway, it has failed the epistemic
test before the real experiment begins.

## Attack 6 — The living tradition is not laboratory apparatus

A public structural description can support research design.

It does not grant authority to:
- extract restricted ritual;
- force practitioners into alien procedure;
- claim one protocol represents all lineages.

If a clean public implementation cannot be agreed upon, select another platform.

## Attack 7 — 1,000-ish trials can still leave meaningful uncertainty

A calibration estimate around 0.5 with N~1000 still has roughly three percentage
points of 95% uncertainty.

If a later claimed anomaly is only two percentage points, the calibration is
too coarse.

Design calibration precision relative to the minimum future effect worth
testing.

## Strongest surviving plan

1. bind exact public procedure;
2. freeze version;
3. run null-only calibration;
4. model bias/dependence/operator effects;
5. freeze the correct null;
6. only then design hidden targets.

## Claim ceiling

No calibration pattern is evidence of contact.
